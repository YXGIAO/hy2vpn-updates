客户端检查接口

客户端启动时调用，自动判断是否需要更新

GET /api/v1/updates/latest?platform=android&channel=stable&current=1.8.0
  • platform：android 或 windows
  • channel：stable（默认）或 beta
  • current：当前已安装版本号，如 1.8.0
  • 返回 updateAvailable、release.version、release.force、release.downloadUrl

如何发布新版本

安装包自行托管，后台只登记版本号与下载直链

  1. 准备好安装包直链

    把安装包放到对象存储、网盘或自有服务器，复制一个能在浏览器地址栏直接打开并开始下载的链接（http:// 或 https://）。

  2. 在管理后台登记版本

    点击右上角「管理后台」，输入 Pages 中配置的 ADMIN_TOKEN。Windows 与 Android 分开填写：版本号、下载链接、更新说明，Android 还需要递增的 versionCode。

  3. 发布

    新建时可勾选「草稿」或「预发布（Beta）」；确认后点「发布」，需要强制升级时勾选「强制更新」。客户端两分钟内即可检测到。

  4. 验证

    刷新本页，或访问 /api/v1/updates/latest?platform=windows&current=0.0.0，确认返回的 downloadUrl 可以正常下载。

修改版本号或下载链接会立即生效；页面数据最多缓存 30 秒。
