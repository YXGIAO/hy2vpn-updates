客户端检查接口

客户端启动时调用，自动判断是否需要更新

GET /api/v1/updates/latest?platform=android&channel=stable&current=1.8.0
  • platform：android 或 windows
  • channel：stable（默认）或 beta
  • current：当前已安装版本号，如 1.8.0
  • 返回 updateAvailable、release.version、release.force、release.downloadUrl

如何发布新版本

在 GitHub 新建 Release 即可，无需改动本服务

  1. 构建安装包

    Windows 生成 HY2VPN-Desktop-Setup-x.y.z.exe；Android 生成 HY2VPN-x.y.z.apk（签名版）。

  2. 创建 Release

    标签必须以平台开头：windows-v1.4.0 或 android-v1.9.0。Beta 版本勾选 Set as a pre-release。

    gh release create windows-v1.4.0 ./HY2VPN-Desktop-Setup-1.4.0.exe \
  --title "Windows 1.4.0" \
  --notes "新增：客户端更新检查"

gh release create android-v1.9.0 ./HY2VPN-1.9.0.apk \
  --title "Android 1.9.0" \
  --notes "versionCode: 13
新增：客户端更新检查"
  3. 可选标记

    说明里单独一行写 versionCode=13 供 Android 使用；写 force=true 表示强制更新。客户端会先比较版本号，满足条件才提示。

  4. 验证

    发布后刷新本页，或访问 /api/v1/updates/latest?platform=windows&current=0.0.0 确认能看到新版本。

发布顺序建议：先上传安装包并发布 Release，再推送带新版本号的客户端代码。
