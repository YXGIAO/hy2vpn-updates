客户端检查接口

客户端启动时调用，自动判断是否需要更新

GET /api/v1/updates/latest?platform=android&channel=stable&current=1.8.0
  • platform：android 或 windows
  • channel：stable（默认）或 beta
  • current：当前已安装版本号，如 1.8.0
  • 返回 updateAvailable、release.version、release.force、release.downloadUrl

如何发布新版本

推荐使用「管理后台」，也可直接在 GitHub 新建 Release

  1. 打开管理后台

    点击右上角「管理后台」，输入 Pages 中配置的 ADMIN_TOKEN，即可新建版本、上传安装包、维护更新说明与强制更新标记。

  2. 构建并上传安装包

    Windows 生成 HY2VPN-Desktop-Setup-x.y.z.exe；Android 生成 HY2VPN-x.y.z.apk（签名版）。超过上传上限的大文件可在 GitHub 网页版上传后再回后台调整状态。

  3. 检查与发布

    后台创建版本时可选「草稿」「预发布」；确认无误后点击「发布」或「设为稳定」，客户端两分钟内即可检测到新版本。

  4. 验证

    刷新本页，或访问 /api/v1/updates/latest?platform=windows&current=0.0.0 确认能看到新版本。

发布顺序建议：先上传安装包并发布 Release，再推送带新版本号的客户端代码。
