发布流程

安装包放在任何支持直链下载的地方，这里只登记版本信息

  1. 先上传安装包，拿到直链

    可放在对象存储、网盘或自有服务器；链接需能直接在浏览器地址栏打开并开始下载（http:// 或 https://）。

  2. 新建版本

    选择平台，填版本号（如 1.4.1 / 1.10.0）、下载链接与更新说明；Android 还需填写递增的 versionCode。

  3. 发布并验证

    草稿 → 点「发布」；Beta 版本 → 点「设为稳定」。发布后打开 /api/v1/updates/latest?platform=windows&current=0.0.0 确认返回的 downloadUrl 正确。

建议先在无痕窗口打开一次下载链接，确认普通用户能直接下载；链接里的文件名最好带版本号，方便识别。
